## 口径与证据

指数采用同花顺代码。文档举例包含白酒概念 886042.TI、沪深 300 000300.SH、上证综指 000001.SH 与深证成指 399001.SZ。真实运行如果上游针对某一指数返回无权限、无数据、限流或接口错误，工具就记录失败。

一个 N 日区间需要 N+1 个收盘点位。日历按上海时区查询，盘中截至前一自然日，再向前定位最近的完整交易日。检查每个应有交易日的日线，并按日历对齐研究指数与基准。区间涨幅为 (期末点位 ÷ 期初点位 − 1) × 100%，相对表现为两者累计涨幅之差，单位为百分点。比较值保持原精度，展示层负责格式化。

每组行情保留查询 URL、服务器返回的请求标识（如有）、取数时间、原始价格字段、交易日和日历来源。周末及节假日实际取样末日可能早于查询截止日。日历明显滞后、缺少收盘价、价格无效、重复或冲突记录都会阻止正常计算。指数收盘序列不能推断成分股普涨比例。扶摇成分接口返回当前清单，历史复盘若使用它还需验证成分变动。

## 可重复验证

运行 `node --test test/providers.test.mjs`。测试用构造交易日与价格验证手算的 10 个百分点收益差、缺值和冲突、日期错位，以及 HTTP 200 中携带的业务权限错误。该测试不会消耗线上额度，也不会保存任何真实行情。

在具备外网 DNS 且配置真实服务端密钥的环境打开实数模式，分别检查计划与行情的来源记录。运行 `npm run verify:live` 复核同一研究流程。2026-11-18 的 Mac 验证经过直接出报告分支，扩展审批分支与远程托管仍需单独验收。若只需要在原候选人目录启动，使用 `node scripts/start-private.mjs` 从上一级私有说明读入密钥，不输出其值，也不生成凭据副本。发布环境应配置平台的服务器密钥管理功能。
