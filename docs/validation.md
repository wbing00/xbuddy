# AI 使用与验证

本项目使用 Codex 参与方案选择、查阅接口文档、实现、测试和验证。产品使用 DeepSeek 进行受限规划，自动测试在 HTTP 边界注入响应。以下记录属于开发过程中的修正，并非候选人已亲自做过的操作。候选人交卷前可补充自己的复核与取舍。

| 原始假设或缺陷 | 验证与修正 |
| --- | --- |
| 初始设计打算用指数与公告判断“是否普涨”和解释涨跌。 | 只看指数不能计算成分股上涨比例；公告与成分尚无已验证链路。实际交付将问题切为区间相对收益和回撤。覆盖率追问会明确缺少分母。 |
| “近 5 日”若只取 5 个收盘点位会少算一个收益间隔。 | 先核对交易日历，查询 6 个点位，使用已知 10 个百分点收益差的样本手算复核。 |
| 扩展查询可能跨越当日收盘，导致前后窗口错位。 | 后续取数钉住首份证据的实际结束日，校验两期交界日及两指数对应日期。 |
| HTTP 成功可能仍是业务无权限；模型可能截断 JSON。 | 注入 HTTP 200 / 业务码 2003 与未正常完成的模型结果，分别走工具错误、模型规划降级。 |
| 页面重开或两次快速点击可能重复执行。 | 对每个步骤加记录版本与租约，两次并发推进同一检查点只有一个成功。 |

## 自动验证

用 `npm test` 运行。数据适配测试使用模拟的上游响应，线程测试从实际 API 路由进入，经过与产品相同的工具选择、状态更新和产物生成。

- 正常路径：创建、暂停、重新读取、恢复、扩展审批、产出简报，验证每条事实引用了已存储的证据，检查 20+20 日两个窗口准确衔接。
- 跳过审批：不多取数据，按原范围产出简报。用户明确勾选的偏好可在新任务读取。
- 模型无凭据：采用有限的确定性规划并留下事件。行情无凭据：停止数据步骤，连续重试触发上限，阶段报告不生成数值事实。
- 数据异常：缺失中间交易日、空值、重复记录、日期不同、上游无权限及模型输出截断。
- 边界：直接交易建议请求在调用工具前结束。并发或陈旧版本收到 409。

## 仍需现场复核

凭据是否能在线读取目标指数、官方实时权限、实际费用、浏览器视觉及远程 URL 的评审者可访问性必须在可联网并可启动浏览器的环境复核。构造样本覆盖执行逻辑，不能证明真实账户权限。
