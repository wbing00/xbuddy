# 投资 X Buddy

面向晨会准备的 A 股研究工作台。研究员给出目标，选择一个指数、基准和 5 / 10 / 20 个交易日，取得包含原始收盘点位、区间比较、回撤及证据引用的简报。适合用“白酒概念相对沪深 300 的表现是否延续了前一期？”体验。行情差异以百分点展示，不作因果或交易判断。

## 实数评审服务

[部署到 Render](https://render.com/deploy?repo=https://github.com/wbing00/xbuddy)。部署时在平台填写 FUYAO_API_KEY 和 DEEPSEEK_API_KEY。服务端默认选择在线查询。验收可用上证综指、沪深300和 5 日窗口，在日志里查看两次模型决策，在证据页核对行情时点。Render 免费实例使用临时文件系统，实例重启、休眠或重新部署后，SQLite 线程及偏好可能丢失。

GitHub Pages 提供入口说明。真实研究在服务端工作台发起，教学样本用于自动测试和单独的离线演练文件。

## 本地运行

需要 Node.js 22.13 或更高版本，无第三方依赖。在这个源码目录中运行：

```sh
npm start
```

浏览器打开 http://127.0.0.1:4173 。默认绑定本机。服务端新建线程只接受实数模式。实数模式读取服务端环境变量。可通过系统环境设置，也可从 .env.example 复制一份忽略提交的 .env.local。原笔试工作区中另可直接运行 `npm run start:private`，它仅在内存读取上层目录里候选人准备的凭据。独立仓库无需这份私有说明也可启动服务端，实数查询需要上述密钥。

| 环境变量 | 用途 |
| --- | --- |
| FUYAO_API_KEY | 扶摇交易日历和指数日线 |
| DEEPSEEK_API_KEY | DeepSeek 研究规划及取数后的计划调整 |
| DEEPSEEK_MODEL | 可覆盖默认模型名，须支持 JSON 输出 |
| PORT / HOST | 本地服务端口和绑定地址 |

运行 `npm test` 执行数据层和工作流验证。`npm run build` 生成 Sites Worker 以及可双击的 `dist/离线演练.html`。该单文件使用同一套界面、研究流程和计算，在当前浏览器保存演练线程。真实模式需要服务端。浏览器需允许本地存储。

## 两分钟验收

1. 选择“晨会复盘简报”模板、白酒概念、沪深 300 和在线模式，开始研究。在任务页观察已经完成的查询，按“暂停研究”。
2. 刷新后在原线程继续。线程沿用已取得的 E1 / E2，生成 C1。本期比较需要 N+1 个价格，从期初收盘观察 N 个收益间隔。
3. 批准查询前一个窗口，或跳过直接交付。在简报里点击源引用，核对日期、原始数值、单位和公式。试问“本次使用了多少个交易日？”并下载 Markdown。
4. 新建实数线程可检查实际服务权限。模型失败有降级日志；行情无权限、缺失或冲突会阻止计算。可以重试或只交付已有证据。勾选“记住基准和观察窗口”后，新任务沿用该偏好。

## 工程决策

- **模型与工具**　程序从注册表构建任务与权限清单。实数模式下，模型在准许的收益/风险口径内选择研究重点；得到行情后，下一次模型调用读取压缩检查点与计算值，选择出具简报或申请扩展范围。取数、口径校验、数值计算和引用组装由程序执行。
- **上下文与记忆**　线程保留目标、参数、任务、审核决策、证据、用量和事件。传给后续模型的是目标、检查点、证据编号及必要的指标，不传完整 K 线。用户明确选择保留的偏好独立存储；后续可用原始证据回答受支持的追问。
- **恢复与并发**　每次请求最多推进一个步骤。工具返回后提交检查点。本地 SQLite 保存记录，Worker 使用 R2。请求携带版本号并用条件写入抢占短租约，拒绝过期版本；意外中断后租约 90 秒过期，可重新读取最近检查点。只读外部查询在崩溃窗口可能重发一次。页面关闭后任务停在检查点，需要主动继续。
- **执行约束**　额外的对照窗口须经用户批准。外部模型与行情工具均有超时；每线程最多 12 次逻辑调用，最多累计 240 秒活动时间，达到上限时于步骤边界交付阶段结果。一次行情工具内部最多两次 HTTP 请求。单步骤最多重试两次。记录模型实际返回的 token 数、逻辑调用数及运行耗时；未接入账单接口，没有声称精确货币费用。
- **数据隔离**　实数与演练从建线程时分开，数据失败不会切换成演练。托管入口使用平台身份或访客 Cookie，本地服务使用 HttpOnly Cookie 将线程隔离。演练输入不需要真实持仓或身份信息。
- **已知边界**　指数收盘序列只支持区间表现和区间内最大回撤。成分股上涨宽度、公告、资金流和估值归因尚无已验证的数据链。追问覆盖报告已有指标与口径；未覆盖的问题会返回证据不足。当前以单人研究和短时间内的交互式执行为交付范围。
