# 投资 X Buddy

输入投资研究问题后，DeepSeek 读取问题、可用工具、已有证据与执行记录，提出下一步调查。系统校验并执行工具，将结果保存在线程里。后续轮次可以查其他数据、向用户澄清、提交带引用的简报，或说明具体缺口。

## 运行和验证

需要 Node.js 22.13 以上。原笔试工作区运行 `npm run start:private`，打开 http://127.0.0.1:4173 。独立仓库可从 .env.example 创建 .env.local，填入密钥后运行 `npm start`。

| 环境变量 | 用途 |
| --- | --- |
| FUYAO_API_KEY | 扶摇交易日历、指数行情、期货目录与日线、股票快照和资金数据 |
| DEEPSEEK_API_KEY | 编排、根据证据决定下一步和生成简报 |
| DEEPSEEK_MODEL | 可选，覆盖默认 deepseek-flash |
| IFIND_MCP_URL / IFIND_MCP_KEY | 可选，从 iFinD 后台复制有权限的 Streamable HTTP 服务地址及其授权密钥。原工作区启动器可读取上层私有说明中的 MCP 密钥，URL 仍需配置。 |
| HOST / PORT | 本地监听地址和端口 |

运行 `npm test` 执行隔离网络的回归测试。`npm run verify:live` 用真实凭据运行新版编排器，输出工具动作、来源、请求编号和最终状态。默认问题是上证综指近五日表现，可用 RESEARCH_QUESTION 设置其他问题。命令行遇到澄清或审批会停下，完整交互从浏览器进行。

## 评审体验

- 输入“分析黄金最近的表现”。现货、期货与 ETF 有不同口径。选择沪金主连时，系统可以先查国内期货主连目录、从返回结果中选择合约，再查询日 K。应从证据页核对合约、数据日期和价格。权限取决于扶摇账号。
- 输入“上证综指最近五个交易日表现如何？”，随后追问“同期与沪深300相比呢？”。在简报下方以“发送”开始对话。解释类问题基于原简报和已有证据回复；询问新的事实时可以补查基准。问答记录保存在同一线程，保持原简报及其导出内容。
- 输入“贵州茅台（600519.SH）的行情和主力资金分别如何？”。行情和资金快照属于不同工具。查看任务记录核实是否分别取数；没有权限或数据缺失时，查看失败记录及剩余证据。
- 可在设置中记住未指定口径时使用的窗口和基准。在任务页暂停、刷新并恢复；点开简报中的证据编号核对原始数据，或下载 Markdown。

## 工具与执行边界

一个线程初始只有规划任务。每次推进最多执行一个决策或工具。扶摇调用的端点、可用参数、范围和访问密钥由服务端控制；期货日线代码必须来自本线程的目录结果。程序负责行情区间收益、最大回撤和日期对齐比较。模型返回的事实须引用本线程已有证据，引用存在性校验不能替代对文字结论的人工复核。

配置 iFinD 后，模型可请求发现工具，服务端从官方 MCP 服务返回的目录中筛选只读查询，按返回的名称和参数调用。具体覆盖范围取决于该服务和账号权限。iFinD 数据查询需要用户批准。已有两份证据后，额外的外部读取也需要批准。用户可以跳过调查，模型会收到该决定。

每线程最多 24 次逻辑调用、累计 240 秒活动时间。记录模型 token、调用数、耗时、失败和审批。SQLite 或 R2 保存线程，版本和短租约保护并发；关闭页面后可主动从检查点继续。工具失败会返回规划器，模型可改走已注册路径或说明缺口。有限重试用于模型故障，数据源不会降级到模拟数据。旧版实数线程保留原有恢复逻辑。当前未支持交易下单、所有市场的行情或后台持续执行。

## 部署与验证记录

[部署到 Render](https://render.com/deploy?repo=https://github.com/wbing00/xbuddy) 可部署 Node 服务。免费实例重启时 SQLite 数据可能丢失。Sites Worker 使用 `npm run build` 打包并需要 BUCKET 存储绑定。GitHub Pages 只提供入口说明。

旧版指数主链路已由候选人使用真实扶摇及 DeepSeek 验证。新版编排器、期货、资金和 iFinD 工具需在有网络和账号权限的环境复核。[数据与账号记录](docs/provider-verification.md) · [AI 使用与测试说明](docs/validation.md)
